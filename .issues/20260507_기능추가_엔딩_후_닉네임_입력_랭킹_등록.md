## 제목

⚙️ [기능추가][랭킹][엔딩][닉네임] 엔딩 컷씬 종료 후 닉네임 입력 + 랭킹 등록 화면 구현

## 본문

## 📝 현재 문제점

- 현재 `/ending/alive` 또는 `/ending/silhouette` 컷씬이 끝나면 곧바로 `/ranking`으로 이동하지만, `/ranking`은 placeholder 상태이고 점수에 사람을 식별할 수단이 없다.
- PRD §6 "활용: 부스 일일 랭킹 보드 운영" / §11 "랭킹: 화이트보드 / 디지털 보드"에 정의된 부스 운영 기능이 비어 있음.
- 결말(성공/실패)에 관계없이 모든 플레이어의 점수가 랭킹에 들어가야 부스 회전 동기가 살아남(실패해도 "재도전"의 의미가 생김).
- 현재는 한 플레이가 끝나면 점수가 어디에도 남지 않아 운영자가 수기로 적어야 하는 상황.

## 🛠️ 해결 방안 / 제안 기능

- 엔딩 컷씬(`/ending/alive`·`/ending/silhouette`) 자동 전환 종료 시점에 닉네임 입력 화면을 노출.
- 결말 분기와 무관하게 동일한 입력 흐름. 닉네임이 등록되면 누적 점수와 함께 로컬 랭킹에 저장.
- `/ranking` 페이지는 저장된 기록을 점수 내림차순 정렬해 보드 형태로 표시.
- 입력은 한국어/영문/숫자 모두 허용, 길이 제한과 비속어/공백만 입력 등은 후속 튜닝 항목.
- 저장은 우선 브라우저 로컬(저장소 1차 후보: `localStorage`)에 한정. 부스 운영상 단일 PC를 사용하므로 충분. 서버 동기화는 후속 이슈.
- 입력 스킵(닉네임 비워두고 진행) 정책은 운영 회전율 우선이면 허용, 랭킹 정합성 우선이면 강제 입력 — 본 이슈에서 한쪽 선택.
- 운영자 단축키(예: ESC로 다음 플레이어 즉시 진입, 랭킹 보드 리셋)는 후속 이슈로 분리 가능.

## ⚙️ 작업 내용

- 엔딩 흐름 변경
  - `/ending/alive`, `/ending/silhouette` 컷씬 종료(또는 키 입력 즉시 전환) 후 `/ranking`으로 직행하지 않고 닉네임 입력 단계 경유
  - 결말과 점수는 입력 단계까지 그대로 보존
- 닉네임 입력 화면
  - 입력 박스 + 등록 버튼 (또는 Enter)
  - 표시: 현재 점수, 결말 outcome(성공/실패) 작게
  - 길이/문자 제약은 가변(가능하면 config 외부화)
  - 부스 가독성 우선 (큰 글씨, 한글 IME 충돌 없는 입력 처리)
- 랭킹 저장소
  - 로컬(예: `localStorage`) 기반 단순 저장 / 조회 / 추가 / 초기화 인터페이스
  - 저장 항목: 닉네임, 누적 점수, 결말 outcome, 기록 시각
  - 운영자 리셋 경로(임시 — 부스 시작 시 일괄 초기화)
- 랭킹 페이지 구현
  - 점수 내림차순 Top N 표시(N 가변), 동점 처리 정책 포함
  - 방금 등록된 본인 기록 하이라이트
  - 부스 보드 가독성 (큰 글씨, 행 간격 등)
  - 일정 시간 후 또는 키 입력 시 타이틀 복귀(다음 플레이어 회전)
- 라우팅
  - 닉네임 입력 단계의 라우트 위치(예: `/ranking/register` 또는 컷씬 내부 단계로 흡수) 선택
  - `/ranking`은 보드 자체에 집중
- 튜닝 파라미터 외부화
  - Top N 개수, 닉네임 길이 제한, 자동 복귀 시간, 동점 정렬 기준 등
- PRD 갱신
  - §6 / §11 랭킹 운영 항목에 본 이슈로 들어온 동작 흐름 반영
- 본 이슈에서 제외(후속 이슈)
  - 서버 기반 다기기 동기화
  - 비속어 필터, 욕설 차단
  - 운영자 보드 리셋 UI / 단축키 강화
  - 시즌별 랭킹, 일별/주별 보드 분리
