## 제목

⚙️ [기능추가][미니게임] 병렬 진행 게임(4번) 구현

## 본문

## 📝 현재 문제점

- 1·2·3번 미니게임은 독립 섹션으로만 동작
- PRD §2.4의 병렬 진행 모드(좌·중·우 3분할 동시 진행) 미구현

## 🛠️ 해결 방안 / 제안 기능

- PRD §2.4 명세대로 병렬 진행 미니게임 구현
- 화면을 좌·중·우 3분할: 좌(10초 맞추기 ←), 중(색상반응 ↑), 우(캐치 →)
- 10초 동안 동시 진행하며 각 게임 점수를 합산하고 2배 보너스 적용
- 캐치 게임 아이템 속도 1.5배 가중
- 1·2·3번 컴포넌트는 건드리지 않고, 4번 안에서 idle/result 사이클 없이 직진 동작하는 미니화 버전을 자체 구현
- 점수 판정 utils(gameUtils, reactionUtils, catchUtils)는 import해서 재사용
- 점수 누적은 4번 내부 로컬 state로 관리 (전역 store는 보스전 도입 시점에 추가)

## ⚙️ 작업 내용

- components/ParallelGame/ 폴더 생성
- 좌·중·우 3분할 레이아웃 (CSS grid 또는 flex)
- 좌측 패널: 10초 타이머 미니화 (←키 입력 시 10초와의 오차로 점수)
- 중앙 패널: 색상반응 미니화 (3~7초 사이 색 변경, ↑키 입력 시 반응시간으로 점수)
- 우측 패널: 캐치 미니화 (속도 1.5배, →키 입력 시 위치로 점수)
- 10초 글로벌 타임라인 + 동시 키 입력 처리 (←/↑/→)
- 점수 누적 로직 + 최종 점수 = (좌 + 중 + 우) × 2
- 결과 화면 (각 게임별 점수, 합계, 2배 보너스 적용 총점)
- App.jsx에 섹션으로 연결
- 사전 의존: 캐치 게임(3번) 이슈 선행 머지 필요
