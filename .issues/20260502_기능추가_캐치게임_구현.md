## 본문

## 📝 현재 문제점

- PRD에 정의된 4개 미니게임 중 1번(10초 맞추기), 2번(색상반응)만 구현되어 있고 3번(캐치) 미구현
- 다음 단계인 4번(병렬 진행) 구현을 위해 3번이 선행되어야 함

## 🛠️ 해결 방안 / 제안 기능

- PRD §2.3 명세대로 캐치 미니게임 구현
- 위에서 아래로 떨어지는 아이템을 화면 중앙 빨간 원 위치에 도달했을 때 → 키로 잡는 방식
- 10초 동안 5~7개 아이템 무작위 등장
- 점수 기준: 정확한 위치(빨간 원 안) 50점, 약간 벗어남(±20px) 20점, 빨간 원 밖/놓침 0점
- 아이템 종류 3가지 (예: 별, 보석, 코인)
- 1·2번 게임과 일관된 컴포넌트 구조와 자체 테마(예: 마법구슬 캐치) 적용
- 결과 화면에서 등급/별점/총점 표시

## ⚙️ 작업 내용

- components/CatchGame/ 폴더 생성 (기존 1·2번 패턴 준수)
- CatchGame.jsx: phase state machine (idle/running/result) + RAF 기반 아이템 낙하
- catchUtils.js: 위치 판정 및 점수 산출 로직 분리
- CatchGame.css: 자체 테마 CSS art (배경, 빨간 원, 아이템 스프라이트)
- 결과 패널 UI (1·2번과 톤 일치)
- App.jsx에 섹션으로 연결
- 키 입력: → 방향키 + 페이지 스크롤 방지 처리
