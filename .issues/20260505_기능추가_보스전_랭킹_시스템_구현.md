# 본문

## 📝 현재 문제점

- 이슈 #16 작업으로 미니게임 4(병렬 진행)까지 완성되었으나, 5단계 보스전은 placeholder("(별도 이슈에서 구현 예정)")만 표시되는 상태
- ParallelGame.jsx에서 보스전 데미지 산출 토대로 누적 점수를 적립해두었으나 아직 사용되지 않음
- 보스전이 비어있어 게임 클라이맥스가 미완성 — ending 씬으로 바로 넘어감
- 랭킹전 컨셉(4번 미니게임 idle 패널에서 "최대 점수" 표기 제거한 이유)이 실제 시스템으로 연결되어 있지 않음
- 사용자가 자기 최고 기록이나 다른 플레이어와의 점수를 비교할 방법이 없음

## 🛠️ 해결 방안 / 제안 기능

### 1. 보스전 메커니즘

- 보스의 체력바와 용사 누적 포인트를 표시하는 보스전 씬 구현
- 사용자가 공격 입력 시 보스 체력에서 누적 포인트만큼 차감
- 누적 점수는 보스전 동안 그대로 보존 (랭킹 데이터로 활용). 매 공격 데미지로 그대로 사용
- 예시: 누적 포인트 800, 보스 체력 2000
  - 1회 공격: 2000 → 1200 (데미지 800, 누적 점수 800 보존)
  - 2회 공격: 1200 → 400
  - 3회 공격: 400 → 0 이하 (보스 사망)
- 즉 보스 체력 ÷ 누적 포인트 = 필요 공격 횟수 (올림)
- 보스 체력 0 이하 → 클리어 → 랭킹 등록 → ending 씬 전환
- 갑옷 + 검 장착한 그린이 vs 보스 대치 구도

### 2. 랭킹 시스템

- 보스 처치 후 누적 점수(`gameStore.totalScore`)를 랭킹 점수로 등록
- 닉네임 입력 UI (클리어 후)
- 본인 최고 기록 + 전체 TOP N 표시
- ending 씬 또는 별도 랭킹 페이지에 본인 순위 강조 + 상위 랭커 표시
- 점수 동률 처리 기준 협의 필요 (클리어 시간 등 부가 기준)

## ⚙️ 작업 내용

### 보스전

- 보스전 전용 컴포넌트 신규 작성 (BossFightScene)
- 보스 체력 상수 정의 (디자이너 협의 필요, 예: 2000)
- 보스 체력바 UI (현재 체력 / 최대 체력 시각화)
- 누적 점수 / 공격 1회 데미지 표시 UI (둘은 동일 값)
- 공격 키 핸들러 (예: Space, Enter, 또는 화살표 키)
- 공격 시 보스 체력에서 데미지 차감 + 피격 애니메이션
- 보스 사망 처리 (체력 0 이하) + 사망 연출
- 누적 점수 0 이하인 경우 처리 (공격 데미지 0 = 보스 처치 불가 → 패배 / 협의)
- 갑옷 그린이 스프라이트 (별도 이슈에서 처리되면 자연 연동)
- App.jsx 라우터에서 boss_fight placeholder 분기를 실제 컴포넌트로 교체
- idle 패널에 보스전 안내 + 공격 방법 명시 (예: "Space로 공격!")

### 랭킹

- 데이터 저장 방식 선정 (옵션 A vs B 협의 필요)
  - 옵션 A: localStorage 단일 사용자 기기 고유 랭킹 (백엔드 없음, 즉시 구현 가능)
  - 옵션 B: 백엔드 + DB (전체 사용자 랭킹 공유) — 별도 인프라 구축 필요
- 닉네임 입력 UI (보스 클리어 후)
- 랭킹 등록 로직 (저장 방식에 따라 localStorage write 또는 API call)
- 랭킹 표시 페이지/섹션 구현
  - TOP N 리스트 (점수 / 닉네임 / 클리어 일시)
  - 본인 순위 강조 표시
- 랭킹 진입 경로 (메인 메뉴 / ending 씬 / 인트로 화면)
- 부가 기준 처리 (옵션, 동률 시 정렬용)
  - 클리어 시간 (빠를수록 가산점)
  - 미니게임 평균 등급 (LEGENDARY 비율)
  - 보스전 공격 횟수 (적을수록 효율적)
- 보스 처치 → 랭킹 등록 → ending 씬 전환 플로우 통합

## 📌 참고

- 누적 점수는 `gameStore.totalScore`에 이미 적립됨 (미니게임 1~4 ADD_SCORE)
- 본 이슈는 누적 점수를 보존하면서 데미지로만 사용 (점수 차감 없음)
- 4번 미니게임 idle 패널에서 "최대 점수" 표기를 제거한 이유가 랭킹전 컨셉 → 본 이슈로 실제 시스템 구축
- 데이터 저장 방식(localStorage vs 백엔드)은 본 이슈 진행 전 결정 필요
- 백엔드 도입 시 익명 사용자 처리 / 비속어 필터링 / 어뷰저 방지 등 추가 고려 사항 발생
- 보스 체력 수치는 난이도 조절 협의 필요 (1500 ~ 3000 사이 추정)
- 보스 디자인 / 그린이 갑옷 스프라이트는 디자이너 협의
- 진입 경로: ParallelGame(미니게임 4) → boss_fight 씬 (현재 라우터 구조 유지)
