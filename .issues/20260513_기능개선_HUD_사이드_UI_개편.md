## 본문

## 📝 현재 문제점

- 좌측 하단 점수 영역이 클릭 가능한 버튼으로 되어 있어 ScoreTable 모달을 열어야 점수 기준을 확인할 수 있음
- 우측 하단에는 진행 텍스트(cleared / 4)만 표시되어, 설명 확인이나 결과 이동 수단이 없음
- Stage 4 완료 시 자동으로 엔딩 페이지로 이동되어 플레이어가 결과 확인 타이밍을 선택할 수 없음

## 🛠️ 해결 방안 / 제안 기능

- 좌측 하단: 점수 버튼 및 ScoreTable 모달 제거 → 스테이지별 점수를 · 구분 텍스트로 표시 (미클리어 시 0)
- 우측 하단: 진행 텍스트 제거 → lucide-react 아이콘 버튼 두 개로 교체
  - Info 아이콘: 클릭 시 간단한 게임 설명 모달 표시
  - LogIn 아이콘: 클릭 시 현재 점수 기준 엔딩 페이지 이동
- Stage 4 완료 후 자동 엔딩 이동 제거 → 허브로 복귀

## ⚙️ 작업 내용

- HudOverlay 우측 하단 아이콘 버튼 2개 추가
