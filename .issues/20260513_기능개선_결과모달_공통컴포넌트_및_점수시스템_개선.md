## 제목

🚀 [기능개선][결과모달][점수시스템] 결과 모달 공통 컴포넌트 통일 및 점수 시스템 개선

## 본문

## 📝 현재 문제점

- 각 스테이지별 결과 모달의 디자인과 구조가 제각각으로 통일되어 있지 않음
- 내 점수가 어떻게 산정되었는지 알 수 없어 결과에 대한 납득감이 낮음
- 스테이지별 점수 만점 기준이 불명확하고 총점 체계가 없음

## 🛠️ 해결 방안 / 제안 기능

- 모든 스테이지에서 공통으로 사용하는 ResultModal 컴포넌트 통일
- 결과 모달에서 각 점수 항목의 오차 범위(기준값)를 함께 표시
- 유저의 점수 결과를 오차 범위 기준으로 하이라이트 처리하여 시각적으로 강조
- 점수 체계 개선: 스테이지 1~3 각 100점 만점, 스테이지 4는 300점 만점, 총 600점 만점

## ⚙️ 작업 내용

- 공통 ResultModal 컴포넌트 신규 제작 및 각 스테이지에 적용
- 점수 오차 범위 표시 UI 설계 및 구현
- 내 결과 하이라이트 처리 로직 추가
- 스테이지별 점수 만점 기준 재정의 (Stage1~3: 100점, Stage4: 300점)
- 총점 집계 및 표시 기능 반영 (600점 만점)
