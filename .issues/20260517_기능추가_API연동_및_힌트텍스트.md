## 본문

## 📝 현재 문제점

- 엔딩에서 닉네임을 입력해도 백엔드로 전송되지 않아 기록이 저장되지 않음 (현재 TODO 주석만 존재)
- 랭킹 페이지(/ranking)는 항상 빈 보드로 노출되어 "아직 기록이 없습니다." 메시지만 표시됨
- 본인 기록을 강조해야 할 highlightId가 항상 null이라 보드 상단/하단 모두 본인 행을 식별할 수 없음
- 사용자가 게임 진행 중 조작/규칙을 직관적으로 파악하기 어려워 힌트 텍스트가 필요함

## 🛠️ 해결 방안 / 제안 기능

- 백엔드 랭킹 API와 실제 연동 (등록/조회)
- .env 기반 API Base URL 설정 추가
- 닉네임 등록 후 응답 받은 id로 본인 행 강조 처리
- 게임 화면에 사용자 가이드용 힌트 텍스트 노출

## ⚙️ 작업 내용

- 환경변수 설정 (.env 기반 API Base URL 적용)
- 랭킹 등록 API 연동 (엔딩 닉네임 제출 시 점수/결말 전송, 응답 id로 highlight 처리)
- 랭킹 조회 API 연동 (/ranking 페이지 진입 시 Top N 데이터 로드)
- 응답 실패/네트워크 오류 시 사용자 피드백 처리
- 게임 진행 화면에 힌트 텍스트 표기 (조작 안내/진행 가이드)
- 힌트 텍스트 노출 위치/타이밍/문구 정의
