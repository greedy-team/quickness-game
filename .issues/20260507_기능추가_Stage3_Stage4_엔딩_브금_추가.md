## 📝 현재 문제점

- 현재 Stage 3(캐치 미니게임), Stage 4(병렬 미니게임), 엔딩 컷씬 화면에 배경 음악(BGM)이 없어 게임 분위기와 몰입감이 떨어짐
- 다른 스테이지 대비 사운드 연출이 비어 있어 일관성 부족

## 🛠️ 해결 방안 / 제안 기능

- Stage 3 진입 시 전용 BGM 재생, 스테이지 종료 시 정지/페이드아웃
- Stage 4 진입 시 전용 BGM 재생, 스테이지 종료 시 정지/페이드아웃
- 엔딩 컷씬 진입 시 분위기에 맞는 BGM 재생, 컷씬 종료 또는 다음 화면 이동 시 정지/페이드아웃
- 기존 트랙 레지스트리(`src/audio/trackRegistry.js`) 패턴을 따라 등록·관리
- 화면 전환 시 이전 BGM이 자연스럽게 정리되도록 라이프사이클 처리
