## 제목

⚙️ [기능추가][UI][사운드] 점수 표기 및 사운드 컨트롤 UI 추가

## 본문

## 📝 현재 문제점

- 만점이 몇 점인지, 삶/죽음을 가르는 기준 점수(현재 700)가 UI에 노출되지 않아 플레이어가 목표/위험 구간을 인지하기 어렵다.
- BGM, 효과음, 보이스 등 각 사운드 음량이 제각각이지만 사용자가 개별적으로 조정하거나 음소거할 수 있는 UI가 없다.

## 🛠️ 해결 방안 / 제안 기능

- 점수 UI 개선
  - 게임 중 현재 점수와 함께 만점, 삶/죽음 분기점(700) 정보를 함께 표기
  - 분기점을 시각적으로 강조하여 플레이어가 위험 구간을 직관적으로 인지하도록 함

- 사운드 컨트롤 UI 추가
  - 우측 상단 등 잘 보이는 위치에 사운드 컨트롤 진입 버튼(아이콘) 배치
  - 버튼을 누르면 사운드 종류별로 개별 조정이 가능한 패널/모달 표시
  - 각 사운드(BGM, 효과음, 보이스 등) 별 볼륨 슬라이더 제공
  - 각 사운드 별 음소거 토글 제공
  - 전체 음소거 토글 제공
  - 설정값은 세션 동안 유지되도록 처리

## ⚙️ 작업 내용

- 점수 표시 영역에 만점, 삶/죽음 분기점(700) 노출
- 우측 상단 사운드 컨트롤 진입 아이콘 추가
- 사운드 컨트롤 패널(개별 볼륨/음소거, 전체 음소거) UI 구현
- 기존 사운드 재생 로직과 볼륨/음소거 상태 연동
