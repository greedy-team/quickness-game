## 제목

🚀 [기능개선][스테이지][Stage3] 스테이지 score 표시 제거 및 Stage3 게임로직 단순화

## 본문

## 📝 현재 문제점

- 각 스테이지 좌측하단에 score가 표시되고 있으나 불필요한 UI 요소로 판단됨
- Stage3는 공간에 들어온 판정 방식을 사용 중이나, 로직이 복잡하고 판정 기준이 모호함
- Stage3에서 가짜 기억(fake memory)이 섞여 있어 게임 의도와 다르게 동작 중
- 오른쪽 화살표(→) 입력 시 반응하는 판정 zone이 y축 상단에 위치해 있어 부자연스러움

## 🛠️ 해결 방안 / 제안 기능

- 각 스테이지 좌측하단의 score 표시 UI 전체 제거
- Stage3 판정 로직을 공간 진입 판정에서 받기(catch) / 못 받기(miss) 두 가지로 단순화
- Stage3에서 가짜 기억 항목 전부 삭제하고 진짜 기억만 남기도록 변경
- → 입력 반응 zone을 y축 하단으로 이동

## ⚙️ 작업 내용

- 모든 스테이지 HUD에서 score 표시 컴포넌트 제거
- Stage3 판정 방식 변경: 공간 진입 판정 → catch / miss 이진 판정
- Stage3 기억 목록에서 가짜 기억 항목 제거, 진짜 기억만 유지
- → 키 반응 zone의 y축 위치 하단으로 조정
