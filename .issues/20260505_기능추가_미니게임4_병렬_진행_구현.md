# 제목

⚙️ [기능추가][미니게임4] PRD §2.4 병렬 진행 미니게임 구현 (1+2+3번 동시 + 2배 보너스)

# 본문

## 📝 현재 문제점

- 이슈 #12 작업으로 scene routing은 완성되었으나 4번 미니게임은 placeholder 화면(제목 + "다음으로" 버튼)만 마련된 상태
- 갑옷을 장착한 그린이가 진행해야 할 클라이맥스 단계인데 실제 게임 로직이 없어 스토리상 빈 단계로 남아있음
- PRD §2.4 명세(1·2·3번을 한 화면에서 동시 진행, 점수 2배, 캐치 속도 1.5배)가 미구현

## 🛠️ 해결 방안 / 제안 기능

- PRD §2.4 명세대로 화면을 좌·중·우 3분할로 구성하고 1, 2, 3번 미니게임을 동시에 진행
  - 좌측: 10초 맞추기 (← 키)
  - 중앙: 색상반응 (↑ 키)
  - 우측: 캐치 (→ 키)
- 게임 시간은 10초 통일
- 각 영역의 점수를 합산한 뒤 2배 보너스 적용
- 캐치 게임 아이템 낙하 속도 1.5배 적용 (난이도 가중)
- 기존 1, 2, 3번 미니게임 컴포넌트의 로직을 재사용하되, 한 화면에 동시 렌더 가능한 형태로 정리
- 갑옷 장착 후 진입하는 단계이므로 그린이 스프라이트는 walk_weapon으로 표시(별도 갑옷 이슈에서 처리되면 자연 연동)
- 종료 시 누적 점수에 합산되어 보스전 데미지 산출 토대 마련

## ⚙️ 작업 내용

- 미니게임 4 전용 컴포넌트 신규 작성 (좌·중·우 3분할 레이아웃)
- 1, 2, 3번 미니게임 컴포넌트 또는 로직을 분할 영역에 동시 렌더 가능하게 정리
- 좌·중·우 각 영역의 점수 계산을 동시에 처리하는 상태 관리
- 점수 2배 보너스 적용 (각 영역 점수 합 × 2)
- 캐치 영역 아이템 낙하 속도 1.5배 적용 (FALL_DURATION_MS 또는 speedMultiplier 활용)
- 키보드 입력 핸들러가 ←, ↑, → 동시 입력을 각 영역에 분리해 전달
- 결과 패널에 좌·중·우 점수 + 합산 + 보너스 적용 점수 + 등급 표시 (5단계 등급 시스템 사용)
- App.jsx 라우터에서 minigame_4 placeholder 분기를 실제 컴포넌트로 교체
- idle 패널에 게임 설명 + 판정 기준(좌·중·우 각 미니게임 기준 + 2배 보너스 안내) 표시
- onComplete(합산 점수)·onContinue() props 인터페이스 통일
- 화면 stage 1920×960 base에 transform scale 또는 stretch로 fit (다른 미니게임과 일관)

## 📌 참고

- 이슈 #12에서 도입한 등급 시스템 5단계(레전더리/유니크/에픽/레어/일반) 그대로 사용
- 1·2·3번 미니게임의 게임 좌표 시스템 보존 원칙 유지 (CatchGame STAGE_HEIGHT_PX 등)
- 결과 후 onContinue → boss_fight 씬으로 전환 (현재 라우터 구조)
