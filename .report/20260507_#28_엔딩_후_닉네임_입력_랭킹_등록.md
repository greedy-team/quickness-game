### 📌 작업 개요

Stage 4 종료 후 자동으로 `/ranking`(placeholder)으로 빠지던 흐름을, 엔딩 컷씬 → 닉네임 입력 → 랭킹 보드의 단일 흐름으로 통합. localStorage 기반 영속 랭킹 + 본인 행 강조 + 자동 타이틀 복귀까지 부스 회전 동선을 한 사이클로 완성.

### 🎯 구현 목표

- 결말 분기(`alive` / `silhouette`)와 무관하게 동일한 닉네임 입력 흐름 제공
- 라우트 분리 없이 `/ending/:outcome`의 state machine을 6단(`entered → reveal → hold → leaving → register → outro`)으로 확장
- localStorage 기반 단순 영속 랭킹: 누적 점수 + 결말 + 닉네임 + 기록 시각
- `/ranking` Top 10 보드 + 본인 행 강조 + 일정 시간/키 입력 후 타이틀 자동 복귀
- 튜닝 파라미터(자릿수, Top N, 자동 복귀 시간, 저장소 cap 등) config 외부화

### 🔧 주요 변경사항 상세

#### state machine — 6단 흐름
```
entered (rAF) → reveal (revealMs) → hold (holdMs) → leaving (leaveMs)
              → register (사용자 입력)
              → outro (outroMs) → /ranking
```
- `entered` 단계는 `requestAnimationFrame` 1프레임 후 `reveal`로 즉시 전환 → 페이드인 애니메이션이 안정적으로 트리거됨
- `leaving` 자동 진입 외에도 `reveal` / `hold` 중 Space/Enter 즉시 스킵 가능
- `register`에서는 윈도우 keydown listener를 OFF — 폼 내부 Enter만 submit (다른 키는 텍스트 입력에 사용)
- `outro` 검정 페이드아웃은 짧은(400ms) 차폐로 컷씬 → 보드 전환의 시각 점프 완화

#### 닉네임 검증 정책
- `value.trim()` 후 길이만 체크. 빈 입력은 거부, 정규식/금칙어는 본 이슈 범위 밖
- IME `compositionstart` / `compositionend`로 조합 중 상태 추적 → 조합 중 Enter는 submit 차단(한국어 변환 확정용 Enter가 의도치 않게 등록 트리거되는 문제 방지)
- `maxLength={nicknameMaxLength}` HTML 속성과 trim 후 slice 양쪽에서 보장

#### 본인 행 식별 — URL 비노출
- `navigate('/ranking', { state: { highlightId: entry.id } })`로 React Router state 전달
- URL 파라미터/쿼리 사용하지 않음 → 새로고침/공유 시 부작용 없음. 타이틀에서 직접 `/ranking` 진입 시는 `highlightId === null`이라 강조만 비활성

#### 저장소 cap & 동점 정렬
- `storageCap: 200` 초과 시 `ts` 오름차순으로 정렬 후 가장 오래된 항목부터 잘라냄(FIFO)
- 정렬 정책: score desc, 동점이면 ts asc — "먼저 기록한 사람이 위"로 부스 회전 동기 부여

#### 본인 행 강조 분기
- Top 10 안: 해당 행에 `--me` 클래스(노란 배경 + 좌측 4px 라인)
- Top 10 밖: 보드 아래 별도 `myrow` 줄로 "내 기록: N위 — 닉 점수 (결말)" 표시

**특이사항**:
- `EndingPage`의 `appendRankingEntry`는 폼이 빈 입력을 차단하므로 정상 흐름에서 throw 도달 불가하지만, 방어적 try/catch로 감싸 컷씬에 갇히는 사고를 차단하고 outro로 강제 진행
- localStorage 키 `quickness-game.ranking.v1` — 데이터 schema 변경 시 `.v2` 등으로 갱신해 구버전 데이터를 자동으로 무시(자체 마이그레이션 로직 없음 — 부스 1회용 데이터 특성상 단순화)
- `RankingPage`의 `useMemo([])` + `useEffect([])`는 의도된 마운트 1회 스냅샷 — `eslint-disable react-hooks/exhaustive-deps` 명시
