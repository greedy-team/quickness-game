### 📌 작업 개요

Stage 3/4에 phase-gated BGM을 추가하고, autoplay 정책을 회피하기 위한 BGM 자동 unlock 처리를 도입했다. Stage 4의 합체(merge) phase는 골드 발광에서 검정 vignette 클로징 연출로 교체했고, 점프스케어는 단순 팡 등장에서 "등장 → 정적 응시 → 차징(스케일 확대 + Y축 하강)" 3단 시퀀스로 재구성했다.

### 🎯 구현 목표

- Stage 3/4 진입만으로 BGM이 흐르지 않고, 실제 플레이 phase(`running`)에서만 재생되도록 게이트.
- 새로고침 후 첫 사용자 제스처에 BGM이 자동 unlock되어 hub BGM이 끊기지 않도록 보강.
- Stage 4 합체 phase에 호러 톤과 일관된 vignette 어둠 수렴 연출 적용.
- 점프스케어를 "다가옴 → 정면 응시 → 달려옴" 시퀀스로 재구성하여 임팩트 강화.

### ✅ 구현 내용

#### Stage 3 BGM — phase-gated 재생

- **파일**: `src/stages/stage3/Stage3Game.jsx`, `src/assets.js`
- **변경 내용**: `Stage3Game`에 로컬 `<audio>` 엘리먼트와 phase 기반 effect 추가. `mode === 'standalone' && phase === 'running'`일 때만 `play()`, 그 외에는 `pause() + currentTime = 0`. `bgmStage3` 자산 키를 `assets.js`에 등록.
- **이유**: 라우트 기반 `BgmController`만으로는 인트로(idle) 화면에서도 BGM이 깔리는 문제가 있어, phase 단위로 정밀 제어가 필요했다. split 모드에서 Stage 3가 분할로 표시될 때 다른 분할의 오디오와 충돌하지 않도록 `mode` 가드도 함께 둠.

#### Stage 4 BGM — 동일 패턴 적용

- **파일**: `src/stages/stage4/Stage4Host.jsx`, `src/assets.js`
- **변경 내용**: `Stage4Host`에 `bgmAudioRef` 추가. `phase === 'running'`일 때만 재생, `merging` 진입 시 즉시 정지. `bgmStage4` 자산 키를 `assets.js`에 등록.
- **이유**: 합체 phase에 점프스케어 SFX pre-roll이 시작되므로, BGM과 SFX가 겹치면 호러 임팩트가 깎인다. 따라서 `running → merging` 전이 시 BGM을 끊는다.

#### BGM 자동 unlock — 새로고침 후 첫 제스처에서 재생 잠금 해제

- **파일**: `src/audio/BgmController.jsx`
- **변경 내용**: `audio.play()`가 autoplay 정책으로 reject되면 `pointerdown` / `keydown` 리스너를 capture phase에 1회성으로 부착. 첫 제스처 발생 시 리스너 제거 + `play()` 재시도. 라우트 변경/언마운트 시 미발화 리스너 정리.
- **이유**: 새로고침 또는 딥링크로 hub에 직접 진입하면 사용자 제스처가 없어 hub BGM이 무음 상태로 갇힌다. 첫 제스처에서 자동 복구되도록 보강.

#### Stage 4 합체(merge) vignette — radial gradient 어둠 수렴

- **파일**: `src/stages/stage4/Stage4MergeOverlay.css`
- **변경 내용**: 기존 골드 발광(`gold` 색상) 제거. `radial-gradient(circle at center, transparent 0% → transparent 20% → rgba(0,0,0,0.55) 45% → rgba(0,0,0,1) 70%)`로 변경하고, `transform: scale(6) → scale(1)` + `opacity: 0 → 1` + `background-color` 페이드를 4초 keyframes에 분배. 다단 키프레임(0/20/40/60/75/85/100%)으로 가속 곡선 수동 제어, `linear` timing.
- **이유**: 골드 톤은 호러 분위기와 부조화였고, 1초 애니메이션이 4초 phase 동안 frozen으로 멈춰 있어 정적이었다. scale을 크게 두고 점진적으로 줄이면서 opacity와 배경색을 함께 끌어올리는 이중 트릭으로 "가장자리에서 어둠이 좁혀 들어와 화면을 덮는" 인상을 연속 4초 동안 유지.

#### Stage 4 점프스케어 — Phase A 등장 → 정적 응시 → Phase B 차징

- **파일**: `src/stages/stage4/Stage4JumpscareOverlay.css`, `src/stages/stage4/Stage4JumpscareOverlay.jsx`
- **변경 내용**:
  - JSX에 `wobble` 래퍼 추가하여 부모×자식 transform 합성 구조 도입.
  - `image` zoom keyframes를 3단으로 재구성:
    - Phase A (0~15%, 0~300ms): `scale 0.15 → 1.5`, `blur 3px → 0`, `brightness 0.5 → 1.0`. 멀리서 흐릿하게 다가오는 느낌.
    - Pause (15~75%, 300~1500ms): `scale 1.5` 유지. 흔들림/밝기는 wobble 래퍼가 담당.
    - Phase B (75~100%, 1500~2000ms): `scale 1.5 → 9 → 14 → 20` + `translateY 10% → 50% → 85% → 120%`. 비선형 키프레임으로 가속 + Y축 하강 적용.
  - wobble 래퍼: 100ms 사이클 × 12회 = 1.2초 동안 `translateX(±1.2vw)` + `brightness 1.4` strobe (300ms 지연으로 정적 응시 구간에 정확히 정렬).
- **이유**: 기존 0.10 → 1.05 overshoot 후 1.5초 정지는 임팩트가 약했다. 단순 팡 등장이 아닌 "멀리서 다가옴 → 정면 응시(공포의 정적) → 코앞까지 달려와 잘려나감"의 서사를 2초 안에 담기 위해 시간 분할과 가속 곡선을 키프레임 간격 자체로 표현. Y축 하강을 더해 시점이 위로 올라가는(피사체가 덮쳐오는) 시각 효과 보강.

### 🔧 주요 변경사항 상세

#### `BgmController.jsx` autoplay unlock 동작

라우트 변경 시 `audio.play()`를 시도하고, 실패 시 `pointerdown`/`keydown`에 capture-phase 리스너를 등록. 리스너는 1회 발화 후 자기 자신을 제거하며 `play()`를 재시도한다. effect cleanup에서 미발화 리스너도 정리하여 누수 없음.

**특이사항**:
- 리스너는 `capture: true`로 부착되어 일반 키 핸들러보다 먼저 실행되므로, Space 같은 게임 입력이 BGM unlock과 동시에 동작.
- `removeUnlock()`은 이중 호출 안전 (`unlockHandler = null` 가드).

#### `Stage4Host.jsx` phase 머신

`intro → running → merging → jumpscare → done` 5단계. 각 phase는 자체 effect로 분리되어 있다.

- `intro`: Space 키 listener → `running`
- `running`: 3 sub-stage 결과 수집, 모두 도착 시 평균 산출 → `merging`
- `merging`: 점프스케어 SFX pre-roll 시작 + 4초 후 `jumpscare` (BGM은 정지)
- `jumpscare`: 2초 후 `done` + `onResult(aggregate)` 호출
- 언마운트 cleanup으로 SFX 누수 방지

**특이사항**:
- BGM과 SFX는 별도 ref(`bgmAudioRef` / `sfxAudioRef`)로 분리. SFX는 `merging`에서 시작하여 6초간 흐르며 점프스케어 클라이맥스를 덮음.
- `subResultHandlers`를 `useMemo`로 고정하여 sub-stage들의 `useEffect` deps가 갈리지 않도록 보호 (RAF 루프 리셋 방지).

#### `Stage4MergeOverlay.css` 4초 키프레임 분배

| 시점 | opacity | scale | bg-color |
|------|---------|-------|----------|
| 0% | 0 | 6 | transparent |
| 20% | 0.20 | 4 | transparent |
| 40% | 0.45 | 2.5 | rgba(0,0,0,0.15) |
| 60% | 0.75 | 1.5 | rgba(0,0,0,0.5) |
| 75% | 0.95 | 1.1 | rgba(0,0,0,0.9) |
| 85% | 1.0 | 1.0 | rgba(0,0,0,1) |
| 100% | 1.0 | 1.0 | rgba(0,0,0,1) |

scale을 크게 두는 동안 gradient의 transparent 영역이 화면 밖으로 밀려나 사용자 시야는 거의 transparent → 점차 정상 크기로 회복하면서 vignette 반경이 좁아진다. 85% 이후는 frozen 상태로 jumpscare 전이까지 검정 유지.

#### `Stage4JumpscareOverlay.css` zoom × wobble 합성

- `.image`의 `transform: translateY × scale`은 등장 → 정적 → 차징 시퀀스 담당.
- `.wobble`의 `transform: translateX`는 정적 응시 구간 흔들림 담당.
- 두 transform이 부모×자식 관계로 곱셈 합성되어 충돌 없이 동시 동작.

**특이사항**:
- wobble의 `300ms` 지연은 image keyframes의 Phase A 종료 시점(15% = 300ms)과 정렬.
- wobble은 12회 반복 × 100ms = 1200ms로 정적 응시 길이(1500 - 300 = 1200ms)와 정확히 일치.
- Phase B의 `scale 20`은 화면 밖으로 크게 넘쳐 자연스러운 잘림(transform overflow). `object-fit: cover`로 강제 자르지 않고 이미지 본체가 viewport를 벗어나는 방식.

### 📌 참고사항

- `trackRegistry.js`의 `stage3` / `stage4` 슬롯은 의도적으로 `null` 유지. 라우트 기반 BGM과 phase 기반 로컬 BGM이 동시 재생되는 충돌을 방지하기 위해, 스테이지 BGM은 컴포넌트 자체가 소유하는 `<audio>`로 제어한다.
- BGM/SFX 음원은 `BGM_DEFAULTS.volume = 0.7`을 따라 hub BGM과 음량 일치. SFX는 `SFX_VOLUME = 1.0`으로 별도 운용.
- Stage 3 split 모드(Stage 4 분할로 진입)에서는 BGM 마운트 자체를 차단(`mode === 'standalone'` 가드)하여 다중 BGM 충돌 방지.
- 점프스케어 keyframes는 spec(`scale 2.7`)보다 큰 `scale 20`까지 확장되어 있다. landscape viewport에서 화면을 완전히 덮고 자연 잘림이 발생하도록 실측 튜닝된 결과.
