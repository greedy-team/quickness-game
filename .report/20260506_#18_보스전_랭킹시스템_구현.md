### 📌 작업 개요

PRD §3 5단계 보스전과 누적 포인트 기반 랭킹 시스템 구현. 미니게임 1~4에서 쌓인 누적 점수가 보스전 데미지로 그대로 사용되어 보스(HP 2000)를 처치하고, 클리어 후 닉네임을 받아 LocalStorage 기반 랭킹에 등록·표시. 보스/그린이는 sprite-sheet 애니메이션으로 비주얼 적용.

---

### 🎯 구현 목표

- 미니게임 4 placeholder만 있던 boss_fight 씬을 실제 게임 메커니즘으로 채우기
- 누적 점수를 차감하지 않고 데미지로 보존 → 랭킹 점수로 활용
- LocalStorage 기반 랭킹 (백엔드 도입 시 어댑터 한 줄 교체로 마이그레이션 가능)
- 보스/그린이 sprite-sheet 비주얼 + world.png 배경
- 미니게임 4 클리어 → 자동 보스전이 아닌 월드씬 → 보스 체크포인트 Space 진입

### 🔧 주요 변경사항 상세

#### 데미지 클램프 룰 (`bossUtils.clampDamage`)
누적 점수 0/음수/NaN/undefined 모두 1로 클램프해 어떤 경우든 처치 가능. `Math.floor`로 소수점 버림. `BOSS_MAX_HP=2000` 상수.

**특이사항**:
- 패배 분기를 의도적으로 제거 — 룰상 누적 포인트가 0이어도 1 데미지로 무한 공격 시 결국 클리어
- 단위 검증은 DEV-only `console.assert` IIFE 11개로 (테스트 러너 미설치, `parallelUtils.js` 패턴 따름)

#### sprite-sheet 패턴 (`Boss`, `Hero` 공통)
`background-image` + `background-size = frame_w × frames` + `animation: ${name}-play ${duration} steps(${frames}) ${loop ? 'infinite' : 'forwards'}` + `--end-pos` CSS 변수로 끝 위치 지정. caller가 `key={action}` 또는 `key={tick}`로 강제 리마운트 시 애니메이션 처음부터 재생.

**특이사항**:
- 보스 sprite는 시트 자체가 그린이를 향하는 방향이라 `scaleX(-1)` 적용 안 함 (초기 spec과 다름)
- 보스 idle 시트는 8 frames 1.6s, attack 9 frames 1.0s. 그린이 attack 4종은 8 frames 0.6s (thrust만 5 frames 0.4s)
- 그린이/보스 모두 `bottom=181`로 같은 발 라인 정렬

#### LocalStorage 어댑터 정렬·fallback
조회 시마다 `[...entries].sort()`로 재정렬 (불변). `crypto.randomUUID` 미지원 환경 대비 fallback. `localStorage` 접근 실패 시 모듈 레벨 `Map`으로 메모리 fallback + 콘솔 경고.

**특이사항**:
- DEV-only 테스트 IIFE에서 `__reset()`을 호출하므로 dev 모드에서는 페이지 로드마다 랭킹이 초기화됨 — 의도된 동작 (DEV가 prod 데이터 오염시키지 않도록)

#### 진입 플로우 변경 (자동 → 능동)
미니게임 4 onContinue는 `worldStage=5` + `scene='world'` 디스패치만 함. WorldScene의 SCREEN2[1] 보스 체크포인트(centerX=1440)가 활성화되어 펄스 애니메이션 표시 → 그린이가 도착 시 "Space로 입장" 토스트 → Space 키 → `boss_fight` 씬 진입.

**특이사항**:
- 기존 `WorldScene` 코드 변경 없음 — SCREEN2의 보스 체크포인트 디스패치 로직이 이미 `'boss_fight'` 호출하도록 되어 있어 라우팅만 바꿔주면 동작
- 그린이 무기 분기는 `key={action}`으로 sprite 시트 매끄럽게 교체
