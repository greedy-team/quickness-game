### 📌 작업 개요

HUD 오버레이 사이드 UI 전면 개편. 좌측 하단의 클릭형 점수 버튼과 ScoreTable 모달을 제거하고 스테이지별 점수 텍스트로 교체. 우측 하단의 진행 텍스트를 제거하고 설명(Info) · 결과(LogIn) 아이콘 버튼으로 교체. Stage 4 완료 후 자동 엔딩 이동 제거.

**보고서 파일**: `.report/20260513_#39_사이드_UI_개편_점수_텍스트화_및_아이콘_버튼_추가.md`

---

### 🎯 구현 목표

- 좌측 하단: 점수 버튼 + ScoreTable 모달 → 스테이지별 점수 텍스트 (`360 · 0 · 400 · 0`)
- 우측 하단: 진행 텍스트 → Info / LogIn 아이콘 버튼 (lucide-react)
- Info 아이콘 클릭 → 게임 소개 모달 표시
- LogIn 아이콘 클릭 → 현재 점수 기준 엔딩 페이지 이동
- Stage 4 완료 후 자동 엔딩 이동 제거 → `/hub` 복귀

### 🔧 주요 변경사항 상세

#### HudOverlay.jsx
`selectClearedCount`, `TOTAL_MAX_SCORE`, `ENDING_SUCCESS_CUTOFF` 등 점수 바 관련 의존성 전부 제거.
`useNavigate` + `endingOutcomeFromTotal` 추가하여 LogIn 버튼에서 엔딩 분기 처리.
스테이지 점수 텍스트: `[1,2,3,4].map(n => stageResults[n]?.score ?? 0).join(' · ')`

#### InfoModal.jsx — 공포 테마
- 빨간 텍스트 2줄(`info-modal__horror`): `#cc1111` 색상 + 붉은 글로우 + 5초 주기 flicker 애니메이션
- 두 줄이 0.4초 딜레이 차이로 어긋나게 깜빡임
- 모달 테두리: 어두운 붉은색 (`rgba(180,0,0,0.5)`)
- 반응형: 모든 크기 값을 `clamp(min, vw, max)` 적용. 최대 너비 `min(800px, 92vw)`

**버그 수정**:
- `.hud-overlay`의 `pointer-events: none`이 InfoModal backdrop에 상속되어 모달 닫기 클릭 시 뒤 요소까지 클릭되는 문제 발생 → `.info-modal-backdrop`에 `pointer-events: auto` 명시로 해결

#### HudOverlay.css
버튼·진행바 관련 스타일 전부 제거.
아이콘 버튼: 배경/테두리 없이 아이콘만 표시. `filter: drop-shadow`로 가시성 확보.
