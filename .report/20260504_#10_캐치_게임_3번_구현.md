### 📌 작업 개요

PRD §2.3 정의된 3번 캐치 미니게임을 신전·제단 컨셉의 자체 CSS art로 구현. 위에서 떨어지는 장비(검·방패·포션)를 제단(중앙 표적) 위치에서 → 키로 캐치, 정확도에 따라 50/20/0점 부여, 10초 경과 시 등급/별점/통계 결과 표시. 4번 병렬 게임에서 1/3 width로 재사용 가능한 비율 기반 레이아웃.

### 🎯 구현 목표

- 4개 미니게임 중 마지막으로 남은 3번 캐치 구현
- 1·2번과 일관된 phase state machine + 자체 테마 CSS art
- 4번 병렬 진행 게임에서 utils와 컴포넌트 재사용 가능한 구조
- 시각 표적과 판정 존이 일치하여 사용자가 직관적으로 타이밍 파악 가능
- 입력 즉시 결과(PERFECT/GOOD/FAIL/MISS) 피드백

### 🔧 주요 변경사항 상세

#### catchUtils.js
판정 거리는 1.5배 튜닝 후 perfect ±15px / near ±30px / 사거리 90px. 시각 표적과 정확히 매칭(시각 outer 60px = 반지름 30px = near 경계).

스폰 스케줄은 게임 시작 시 한 번 계산: 첫 스폰 800ms, 이후 1400~1700ms 무작위 간격, 최대 6개. 낙하 시간 2초가 게임 종료 전 도달 가능한 시점까지만 스폰.

빨간 원 위치는 `RED_CIRCLE_TOP_RATIO = 0.7`(stage height의 70% 지점). px 고정값 대신 비율로 저장해 4번 병렬 모드에서 stage가 줄어도 자동 비율 유지.

#### CatchGame.jsx
활성 아이템 배열은 `{ id, type, spawnAt }`만 React state로 관리. 위치 정보는 저장하지 않고, 입력 시점에 `(performance.now() - gameStartMs - spawnAt)`로 즉석 계산. setState 비용 최소화.

키 입력 핸들러는 `useEffect` + `addEventListener('keydown')` + `e.preventDefault()` 패턴(1·2번과 동일). closure stale 방지를 위해 `phaseRef`/`activeItemsRef` 미러 ref 활용.

캐치 판정: 활성 아이템 중 빨간 원과 가장 가까운 것 1개를 선택, `judgeHit(distance)`로 점수 산출. 사거리(90px) 밖 입력은 fail 카운트만, 점수 변화 없음. 자연 낙하 종료 시 miss 카운트 증가.

피드백 시스템: `feedback` state + `feedbackTimeoutRef` + 카운터 id로 빠른 연속 입력 시 항상 최신 피드백만 표시(stale clear 가드). 600ms CSS 애니메이션과 동일 시간 후 자동 unmount.

#### CatchGame.css
`.catch-circle`(outer 60px) + `.catch-target-inner`(inner 30px)의 2단 동심 구조. flex 중앙 정렬로 inner가 outer 가운데 위치. 펄스 애니메이션은 box-shadow에 적용해 outer만 호흡감.

신전 요소들 모두 `%` 단위 위치/크기. 좌 기둥 `left: 5%`, 우 기둥 `right: 5%`, 빛줄기 가로 30%, stone platform 가로 20%. stage 폭이 1200px → 400px(1/3 모드)로 줄어도 시각 비율 유지.

피드백 색상: perfect=골드(#ffd700), near=초록(#86efac), fail=회색(#9ca3af), miss=빨강(#f87171). 표적 위로 떠오르며 fade-out하는 0.6초 애니메이션.

**특이사항**:
- v1 구현(world.png 배경 + 무방비 그린이 sprite) → v2(자체 CSS art 신전 테마)로 리워크. 4번 병렬 모드에서 1/3 width로 줄였을 때 sprite가 무대를 가득 채우는 문제 해결. 캐릭터는 이번 미니게임에는 등장하지 않음(서사적으로는 "제단 앞에 무릎 꿇은 그린이").
- 빨간 원 위치를 px(420)에서 비율(0.7)로 전환. 기본 stage height 600 기준 0.7×600=420으로 v1과 동일 위치 유지하면서 4번 호환 확보.
- StarRating 컴포넌트는 1번 게임에서 import해서 재사용(`'../TenSecondsGame/StarRating'`).
