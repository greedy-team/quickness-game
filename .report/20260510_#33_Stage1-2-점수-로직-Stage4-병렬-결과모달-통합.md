### 📌 작업 개요
이슈 #33 — Stage 1·2 의 사운드/점수 로직을 helper + tunable config 로 정비하고, 결과 화면에 tier 메시지·획득 점수를 노출. HUD 좌하단에 SCORE 버튼화 + 점수 기준 표(2x2 grid) 모달을 추가. Stage 4 병렬 모드의 좌·중 pane 결과 표시 결함을 보완하고, 분할 모드 3개 pane(시계·카메라·캐치)의 종료 모달을 공통 `ResultModal` 로 통합. 머징 단계 vignette 가 결과 모달까지 함께 어두워지도록 z-index 를 조정.

### 🎯 구현 목표
1. Stage 1·2 점수 산출을 stage 별 `*.config.js` + `reactionScoring` helper 로 외부화 (React/store 의존 제거).
2. perfect tier 안에서 정밀도 보너스로 동점 발생 최소화, tier 경계점 점수는 보존하는 선형 보간 로직 도입.
3. Stage 1·2 결과 화면에 tier 별 멘트 + 획득 점수 표시.
4. HUD 좌하단 누적 점수를 클릭 가능한 버튼으로 강조하고, 클릭 시 4개 stage 점수 기준을 한 화면(2x2 grid)에 보여주는 `ScoreTable` 모달 제공.
5. Stage 4 병렬 모드 좌(시계) pane 의 결과 UI 부재, 중(카메라) pane 의 결과 모달이 pane 경계를 침범하던 문제 수정.
6. Stage 1·2·3 의 split-mode 결과 표시 코드 중복을 stateless 공통 컴포넌트로 통합.
7. Stage 4 머징 vignette 가 결과 모달 위로 덮이지 않던 시각 결함 수정.

### 🔧 주요 변경사항 상세

#### `pointsForError` ↔ `metricFromPoints` ↔ `scoreFromMetric` 파이프라인
3-단계 변환: raw error(s) → component points(0~160) → metric(0~1) → final score(점). 같은 tier 안 정밀도 차이를 component points 가 흡수하고, `scoreFromMetric` 의 sentinel 보간이 점수 단계에서 동점방지 헤드룸을 만든다. tier 경계 metric 에 대한 score 는 보간 전후 동일 → 기존 tier 라벨링과 일관성 유지.

**특이사항**:
- `bare` tier 의 `maxError: Infinity` 로 항상 매칭 보장 (fallback 분기 불필요).
- Stage 2 의 fake 캐치 / 타임아웃은 reaction time 이 정의되지 않으므로 helper 우회하고 `bareTier.points` 를 직접 metric 으로 변환 → 명시적 처리.

#### `Stage4TimerPane` 종료 흐름
`phaseRef.current === 'running'` 가드 + `setTimeout` 핸들 ref + unmount cleanup 의 3중 안전장치. ArrowLeft 다중 입력 / 타이머 만료 + ArrowLeft 동시 발생 / 컴포넌트가 머지 단계 전환으로 unmount 되는 경우 모두 onResult 가 정확히 1 회만 호출되도록 보장.

**특이사항**:
- `formatTime` 이 JSX node(`<span class="s4-hour-min">11:59:</span>` + 초/ms) 를 반환하므로 `ResultModal.metricValue` 도 node 를 그대로 받도록 타입 비제약 설계.
- `tone` 은 `bare` tier 만 `failed`, 그 외는 `success` (Stage 1 멘트 톤과 일치).

#### `ScoreTable` tier 점수 환산
component points 가 fixed 인 tier(great/good/ok/bare) 는 단일 score 값. perfect tier 만 `points=tier.points`(보너스 0) 를 metric 화한 worst-in-tier 와 `metric=0` (보너스 max) 의 best-in-tier 사이 범위로 표시 → 보너스 폭이 시각적으로 드러난다.

**특이사항**:
- Stage 4 는 다른 stage 와 점수 산식이 동형이지만 tier base points 가 모두 1.33배 (300→400, ...) → 별도 행 분해 대신 "최대 점수 460" 단일 값과 "정밀도 보너스" 힌트로 압축.
- backdrop 클릭 / Esc / × 버튼 3 가지 닫기 경로.

- ResultModal backdrop: 200
- Stage4MergeOverlay: 300 (변경)
