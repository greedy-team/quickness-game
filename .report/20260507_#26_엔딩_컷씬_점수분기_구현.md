### 📌 작업 개요

Stage 4 종료 후 누적 점수를 기준으로 성공(`alive`) / 실패(`silhouette`) 두 가지 엔딩 컷씬으로 분기하는 기능 구현. 단일 컷오프(`ENDING_SUCCESS_CUTOFF=600`) 기반 binary 분기를 도입하고, 분기 결과를 라우트(`/ending/alive`, `/ending/silhouette`)에 직접 인코딩하여 URL을 결말의 단일 진실 공급원으로 삼았다. `EndingPage`를 placeholder 상태에서 state machine 기반 컷씬 화면으로 리팩토링.

### 🎯 구현 목표

- 누적 점수 → outcome(`alive` | `silhouette`) 매핑 헬퍼/셀렉터 추가
- 라우트 자체로 분기 (`/ending/alive`, `/ending/silhouette`)
- `EndingCutscene` presentational 컴포넌트 + `ending.config.js` 단일 튜닝 소스 분리
- state machine: `entered → reveal → hold → leaving → /ranking`
- SFX 슬롯은 `null`로 마련하여 추후 음원 추가 시 코드 변경 없이 활성화 가능
- 신규 자산 `greenie_alive.png` / `greenie_silhouette.png` 등록 + PRD §7 표 갱신

### 🔧 주요 변경사항 상세

#### state machine 흐름

```
entered (opacity 0, transition 0ms)
  ↓ requestAnimationFrame
reveal (opacity 1, transition 1000ms) ── SFX 1회 재생 (null이면 skip)
  ↓ revealMs(1000) 후
hold (정지 노출, 8000ms — PRD §5 "엔딩 10초"의 대부분)
  ↓ holdMs 후 자동 OR Space/Enter 즉시
leaving (opacity 0, transition 500ms)
  ↓ leaveMs(500) 후
navigate('/ranking')
```

총 자동 진행 시간 ≈ `revealMs(1000) + holdMs(8000) + leaveMs(500)` = 9.5초 (PRD §5 "엔딩 약 10초"와 정합).

#### outcome 평가 시점

`StagePage.jsx`의 `endingRouteFromCurrentScore = () => '/ending/${selectEndingOutcome(useGameStore.getState())}'`는 `recordResult(4, metric)` 직후 호출된다. zustand `set`이 동기이므로 같은 tick 내 `getState()`로 합산된 totalScore를 읽을 수 있다. `useEffect`를 경유하지 않고 단발 navigate로 처리.

**특이사항**:
- 새로고침/딥링크 시 URL이 단일 진실 공급원 — 점수 store가 초기화되어도 컷씬은 URL에 따라 결정됨
- `EndingPage` 내부 totalScore는 화면에 "최종 점수 N" 자막용으로만 표시 (분기 결정에는 사용 안 함)
- 잘못된 outcome 값이 들어와도 `RouteTree`에서 두 라우트만 화이트리스트 → 그 외는 `*` 패턴이 `/`로 redirect

#### SFX null skip 패턴

```jsx
useEffect(() => {
  if (phase !== 'reveal') return undefined;
  if (!sfxSrc) return undefined;        // ← null이면 skip
  const audio = new Audio(sfxSrc);
  audio.volume = VOLUME;
  audio.play().catch(() => {});         // 자동재생 정책 실패 시 silent
  return () => { audio.pause(); audio.currentTime = 0; };
}, [phase, sfxSrc]);
```

음원 추가 시 `assets.js`의 `endingAliveSfx: null` → 경로 문자열로 교체만 하면 활성화. 컴포넌트 코드 변경 불필요.
