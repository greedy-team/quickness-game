### 📌 작업 개요

스테이지 전반의 결과 표시 UX를 개선하고 플레이어가 점수 근거를 명확히 이해할 수 있도록 각 스테이지의 결과 모달 및 정보 표시를 보강했습니다. Stage3 진입 카운트다운 추가, 아이템 낙하 속도 랜덤화, Stage4 pane별 결과 정보 표시 및 합산 연출, 엔딩/랭킹 한국어화 등을 포함합니다.

#### Stage1 결과 모달 — exclusive 범위 표시
- **파일**: `src/stages/stage1/Stage1Placeholder.jsx`
- **변경 내용**: tier 범위 표시를 누적식(9.6~10.4)에서 exclusive 밴드 방식으로 변경
- **이유**: 기존 표시 방식에서 상위 tier 범위가 하위 tier 범위를 포함하여 혼동 유발. 예) perfect `9.90~10.10초`, great `9.80~9.90 또는 10.10~10.20초` 형식으로 각 tier가 실제로 해당하는 구간만 표시

  ```
  i=0 (perfect): targetSec ± maxError 전체 범위
  i>0 (그 외):   targetSec ± prevMax ~ targetSec ± curMax 의 양쪽 exclusive 구간
  ```

- 결과 모달 상단 `metricValue`는 측정 시각만 표시 (`9.82초`) — 레이블 문구 제거

### 🔧 주요 변경사항 상세

#### exclusive 범위 계산 로직
```
tier i=0 (perfect): [target - maxError, target + maxError]
tier i>0:           [target - curMax, target - prevMax] ∪ [target + prevMax, target + curMax]
```
`arr[i-1].maxError`를 `prevMax`로 참조하여 이전 tier의 상한을 현재 tier의 하한으로 사용.

#### Stage3 카운트다운 animation reset
`<span key={phase} className="stage3-countdown__text">` — React key 변경으로 DOM 재생성 트리거. `@keyframes s3-countdown-pulse`(opacity + scale)가 phase 전환마다 처음부터 재생.

#### MergeOverlay 점수 표시
pane 3개의 점수를 각각 stagger 애니메이션으로 등장시킨 뒤 합계(`=` 기호 + 총점)를 별도 강조. `Stage4Host.jsx`에서 `results[1~3]?.score ?? 0` 패턴으로 null safe하게 전달.
